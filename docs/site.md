# Landing page (`site/`)

A static page: `site/index.html`, `styles.css`, `main.js`, `img/`. No build step.

## Host it on Cloudflare Pages (owner, about 5 minutes)

1. Cloudflare dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**, and pick
   `NotaNovice-Group/SabiTori` (Cloudflare's GitHub app works with a private repository too).
2. Build settings: Framework preset **None**, Build command **empty**, Build output directory **`site`**,
   Production branch **`main`**.
3. Save and deploy. Every push to `main` redeploys; pull requests get preview URLs. This does not use the GitHub
   Actions budget.
4. Optional: **Custom domains** → add the domain (not chosen yet; the site is live at https://sabitori.pages.dev).

`site/_headers` sets security and cache headers on Cloudflare Pages.

Deploy by hand (how the live site at https://sabitori.pages.dev was published; needs `npx wrangler login` once):

```bash
rsync -a --exclude '._*' site/ /tmp/sabitori-site/ && npx wrangler pages deploy /tmp/sabitori-site --project-name sabitori --branch main --force
```

`--force` keeps it on classic Cloudflare Pages, so the address stays `sabitori.pages.dev`. Copy the folder off an
exFAT disk first, or the hidden `._` files are uploaded too.

## Keep it true

The understanding and scam rows of the numbers table are generated by `scripts/numbers.mjs` (between the
`numbers:start` / `numbers:end` markers) from the same result files as `docs/numbers.md`; `pnpm reproduce` checks
them. The other rows are copied from `docs/numbers.md` with their conditions; change both together. Screenshots in
`site/img/` come from the app (English, 390 x 844 at 2x); the demo video from `apps/app/bench/demo/record.mjs`
(scaled to 1280 px). Before sharing the page, make the repository public and publish a release, or the download
and GitHub links show "not found".
